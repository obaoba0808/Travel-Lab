🚇 T-money 交通卡完整教學

什麼是 T-money 卡？

T-money 是韓國最通用的交通卡，類似台灣的悠遊卡。可以用來搭地鐵、公車、計程車，甚至在便利商店消費。卡片有不同設計（韓流明星、卡通人物），空卡 ₩2,500（約 NT$57）。

哪裡可以買 T-money 卡？

  • 便利商店：CU、7-Eleven、GS25 都有販售（24 小時營業）
  • 地鐵站：站內有自動販售櫃檯（有中文介面）
  • 機場：仁川機場便利商店（推薦！下飛機就能買）
  • 車站：首爾車站、弘大車站、釜山車站都有
💡 提示：建議下飛機後在仁川機場便利商店買，方便搭 AREX 機場快線。卡片設計可以挑自己喜歡的，功能都一樣。

怎麼加值？

有兩種方式：

  • 便利商店櫃檯：跟店員說「Top up please」，出示卡片，給現金，立刻完成。最推薦！
  • 地鐵站加值機：有中文介面，插入卡片 → 選擇金額 → 投入現金 → 拿取收據。適合緊急加值。

加值金額：₩1,000 起，建議一次加 ₩20,000-30,000（約 NT$450-680），避免一直加值。加值後記得拿收據確認餘額。

使用範圍

  • 地鐵：全韓國地鐵路線（首爾、釜山、大邱、光州）
  • 公車：全韓國市區公車（注意：濟州島公車不能用 T-money）
  • 計程車：大部分計程車都可以刷（起跳 ₩4,800，約 NT$110）
  • 便利商店：CU、7-Eleven、GS25 都可以消費
  • 自動販賣機：部分飲料自動販賣機可以用 T-money 付款

折扣優惠

使用 T-money 卡搭地鐵和公車有以下折扣：

  • 地鐵：單程票 ₩1,500 → 刷 T-money ₩1,250（折扣 ₩250，約 NT$6）
  • 公車：單程票 ₩1,500 → 刷 T-money ₩1,200（折扣 ₩300，約 NT$7）
  • 轉乘優惠：地鐵轉公車或公車轉地鐵，30 分鐘內轉乘享有額外折扣（約 ₩450，約 NT$10）

💡 小編真心話：轉乘優惠超重要！首爾大眾運輸很發達，常常需要轉乘。記得刷卡进站和出站（地鐵），或刷卡上車和下車（公車），系統才會計算轉乘折扣。如果忘記刷卡，會被扣全程最高費率。

怎麼退卡？

餘額 ₩30,000 以下可在便利商店退（手續費 ₩500）。餘額超過 ₩30,000 需到地鐵站客服中心退。

退卡流程：帶卡片到便利商店 → 跟店員說「Refund please」 → 店員操作機器 → 退還卡費 ₩2,500 + 餘額 - 手續費 ₩500。

注意：建議最後一天再去退，避免中間需要再用卡。如果下次還會來韓國，可以保留卡片（餘額不會消失），下次來再加值即可。

🎫 Seoul Pass 完整教學

什麼是 Seoul Pass？

Seoul Pass 是首爾市政府推出的景點通行證，購買後可以在有效時間內免費或折扣進入多個景點。分為 24 小時、48 小時、72 小時三種，時間從第一次使用景點開始計算，連續 24/48/72 小時。

Seoul Pass 種類與價格

種類 價格（₩） 價格（NT$） 適合對象
24 小時 ₩25,000 約 NT$565 行程密集，一天去 2-3 個景點
48 小時 ₩45,000 約 NT$1,015 行程分散，兩天去 3-4 個景點
72 小時 ₩65,000 約 NT$1,465 行程鬆散，三天去 4-5 個景點
💡 提示：建議出發前在官網預購（享 9 折），到韓國後在指定地點領取。現場購買原價，不會有折扣。

Seoul Pass 包含哪些景點？

免費景點：

  • 景福宮（경복궁）：朝�代時代王宮，門票 ₩3,000
  • 昌德宮（창덕궁）：世界文化遺產，門票 ₩5,000
  • 昌慶宮（창경궁）：秘苑導覽，門票 ₩3,000 + 導覽 ₩15,000
  • 德壽宮（덕수궁）：近代歷史博物館，門票 ₩3,000
  • 南山塔展望台（N서울타워）：首爾地標，纜車來回 ₩11,000 + 展望台 ₩16,000
  • 酪山公園（노소공원）：首爾市中心大公園，免費
  • 盤浦大橋噴泉（반포대교분수）：夜晚噴泉秀，免費觀賞

折扣景點：

  • 樂天世界（롯텐월드）：遊樂園，門票 ₩56,000 → Seoul Pass ₩45,000（折扣 ₩11,000）
  • 愛寶樂園（에버랜드）：遊樂園，門票 ₩56,000 → Seoul Pass ₩45,000（折扣 ₩11,000）

注意：有些景點需要提前預約（例如秘苑導覽），建議出發前先預約。完整清單請參考 Seoul Pass 官網。

Seoul Pass 值得買嗎？

如果你計劃去 3 個以上付費景點，Seoul Pass 就值得！

範例計算：

  • 景福宮(₩3,000) + 昌德宮(₩5,000) + 昌慶宮(₩3,000) + 秘苑導覽(₩15,000) = ₩26,000
  • Seoul Pass 24 小時 ₩25,000 就回本
  • 如果再加南山塔展望台(₩27,000)，總共 ₩53,000，Seoul Pass 24h 省 ₩28,000（約 NT$632）

不需要買的情況：如果你只去免費景點（北村韓屋、明洞聖堂、南山塔戶外），就不需要買 Seoul Pass。

💰 韓國自由行省錢 Tips

交通省錢

  • 買 T-money 卡，搭地鐵和公車都有折扣
  • 利用轉乘優惠（30 分鐘內轉乘享有額外折扣）
  • 避免搭計程車長途，地鐵比較便宜
  • 如果行程密集，可以買地鐵一日券（₩15,000，約 NT$340），一天搭 4 次以上就回本

景點省錢

  • 如果去 3 個以上付費景點，買 Seoul Pass
  • 穿韓服可以免費進入景福宮（旁邊有韓服租借店，₩20,000-30,000/2 小時）
  • 很多景點都有「文化日」活動（每月最後一個週三），門票半價或免費
  • 學生證可以有折扣（記得帶學生證）

美食省錢

  • 平價小吃：路邊攤（₩3,000-8,000，約 NT$68-180）
  • 超市熟食區：Emart、Lotte Mart 的熟食區便宜又好吃
  • 便利商店：CU、7-Eleven 的三角飯糰（₩1,000-1,500，約 NT$23-34）
  • 避免明洞、弘大觀光區餐廳，價格較高

購物省錢

  • 機場免稅店線上預購（享 9-15% 折扣）
  • 市區免稅店：新羅免稅店、樂天免稅店，現場逛+直接提貨
  • 明洞街頭櫃位：開放時間營業，價格較高但方便
  • 退稅：單筆消費滿 ₩30,000 可退稅 7-8%，機場海關蓋章後退現金或信用卡

❓ 常見問題

T-money 卡哪裡買？▼
便利商店（CU/7-Eleven/GS25）有賣，空卡 ₩2,500（約 NT$57）。仁川機場、首爾車站、弘大車站也有販售櫃檯。建議下飛機後在機場便利商店買，方便搭 AREX 機場快線。
T-money 卡怎麼加值？▼
便利商店櫃檯或地鐵站內加值機（有中文介面）。加值金額：₩1,000 起，建議一次加 ₩20,000-30,000（約 NT$450-680），避免一直加值。加值後記得拿收據確認餘額。

T-money 卡可以退嗎？▼
可以！餘額 ₩30,000 以下可在便利商店退（手續費 ₩500）。餘額超過 ₩30,000 需到地鐵站客服中心退。退卡時會退還卡費 ₩2,500 + 餘額 - 手續費。建議最後一天再去退，避免中間需要再用卡。
Seoul Pass 有哪些種類？▼
分為 24 小時、48 小時、72 小時三種。24h ₩25,000（約 NT$565）、48h ₩45,000（約 NT$1,015）、72h ₩65,000（約 NT$1,465）。時間從第一次使用景點開始計算，連續 24/48/72 小時。適合行程密集的人。
T-money 卡可以在哪些城市使用？▼
T-money 卡在全韓國通用！首爾、釜山、濟州島、大邱、光州都可以用。搭地鐵、公車、計程車都能刷，甚至在便利商店消費也可以。但注意：濟州島的公車不能用 T-money，需要另外買濟州島專用卡（₩2,000）。
Seoul Pass 包含哪些景點？▼
包含：景福宮、昌德宮、昌慶宮、德壽宮、秘苑導覽、南山塔展望台、N首爾塔、酪山公園、盤浦大橋噴泉、樂天世界、愛寶樂園（部分折扣）。完整清單請參考 Seoul Pass 官網。注意：有些景點需要提前預約（例如秘苑導覽），建議出發前先預約。
